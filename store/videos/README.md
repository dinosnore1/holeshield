# VPN declaration videos

These two screen recordings are for the Play Console **VpnService**
declaration. They were recorded from the signed bundle on a clean Android 15
emulator (1080×1920, no audio, no personal data).

| File | Length | Shows |
|---|---|---|
| `01-vpn-consent.mp4` | 28 s | First run → **Turn on protection** → in-app **VPN disclosure** → **Agree and continue** → Android system VPN prompt → **OK** → **PROTECTED**. |
| `02-vpn-cancel.mp4` | 8 s | The in-app disclosure text → **Cancel** → protection stays **OFF**, no VPN service starts. |

To use them:

1. Upload each file to YouTube as **Unlisted**.
2. Paste the links into the Play Console VPN declaration form.
3. Keep the videos available for as long as the app is listed;
   Play may re-check them during review.

The recordings explain that Hole Shield runs a local, DNS-only VpnService, that
it does not connect to a remote VPN server, that query history stays on the
device, and that the user can turn protection off at any time.
