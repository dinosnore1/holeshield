Verified
--------
- 133 desktop checks pass, including PBKDF2 login, compact gravity index,
  blocked-response modes and blocklist category rules.
- Fresh install on Android 15 (API 35) and Android 16 (API 36) emulators:
  notification permission prompt, in-app VPN disclosure, Android VPN prompt,
  protection on.
- Disclosure Cancel leaves protection off and starts no VPN service.
- Turning protection off and on again with existing system consent does not
  repeat the disclosure.
- Foreground service reports type 0x40000000 (specialUse) on API 35 and 36.
- Start at boot resumes protection on API 35 and API 36.
- 2.0.1 on a VU/Hisense Android 11 TV (non-blocking tun fd): reader thread idle at
  0 CPU ticks in 10 s (was 94 % of a core); protection restarted by itself after an
  app update and after a reboot.
- 2.1.0 web login verified on the TV: username + password enforced, wrong
  user/password rejected, SID and v5 `auth=user:pass` accepted, password-only
  installs remain compatible, and clearing the password reopens the dashboard.
- Version strings now come from the installed package (`2.2.0`).
- 2.2.0 adds explicit tracker/telemetry and malware/phishing list categories.
  The new URLs were downloaded and parsed: URLhaus hosts (1,906 domains) and
  Phishing Army (151,707 domains). Category merge/remove/hasAll is covered by
  the 113 desktop checks. The maximum gravity cap remains 600k.
- 2.2.0 installed on the STB at 192.168.2.133 (versionCode 6 / versionName
  2.2.0). Tracker and malware categories show Active; the final 25-list update
  produced 592,615 unique domains with category counts: ads 526,615, trackers
  3,896, malware 153,613. `02teste.cc` (URLhaus), `0-ilxrc-w285.p9bckp.sbs`
  (Phishing Army) and `app-measurement.com` (tracker) resolve to 0.0.0.0;
  `example.com` resolves normally.
- The web dashboard summary now returns `categories.ads`, `categories.trackers`
  and `categories.malware`; the dashboard renders them in a LIST COVERAGE row.
- The web dashboard has icon-only sun/moon theme and refresh buttons; the theme
  choice is stored in localStorage. Both icons and labels were exercised with
  jsdom.
- The dashboard tab has an inline SVG favicon. A Log out button appears when a
  web login is configured, clears the local SID, invalidates the server session,
  and returns to the login form.
- The web login is a centered full-page form with a title, Authorization
  Required divider, compact pill username/password fields and an arrow submit
  button.
- The dashboard uses Material You color roles and tonal surfaces: filled primary
  buttons, surface-container cards, M3 badges, outlined fields and tonal status
  pills, in dark and light themes.
- The dashboard uses one styled Pause pill (pause icon, native dropdown,
  chevron): choosing a duration (5 minutes through 24 hours, or until resumed)
  pauses immediately. The pill then shows the remaining time and ticks down;
  Resume remains a button. The selected text is left-aligned and the pill width
  grows or shrinks with the label. The paused state uses a class (not :has), the
  native select text is fully hidden, the paused label stays neutral (no red),
  and the focus ring/inset shadow is removed.
- Dashboard, query log, gravity/rules and stats screens verified.
- 2.3.0 installed on the STB at 192.168.2.133 (versionCode 7 / versionName
  2.3.0).
- 2.3.0 adds opt-in dashboard/LAN DNS, notification actions, a Quick Settings
  tile and a home-screen widget. The notification exposes Pause 30 min and
  Resume; the widget pause/resume action was verified with an ADB broadcast.
- The dashboard adds a 24-hour chart, blocked-by-category breakdown, runtime
  Ads/Trackers/Malware switches, per-list health, query-log allow/block actions
  and CSV/JSON export. The new UI was exercised with jsdom.
- Login hardening: PBKDF2-HMAC-SHA256 password records, a 5-attempt lockout,
  HttpOnly/SameSite session cookie and log-out-all epoch.
- Backup/restore uses the system document picker and JSON; compact gravity
  storage uses sorted 64-bit hashes with category flags.
- DNS-over-TLS, selectable blocked response (0.0.0.0/NXDOMAIN/NODATA), blocking
  hours, per-client rules and the optional adult-content list are included.
